🏨 Hotel Booking Cancellation Analysis (EDA Project)
📌 Project Overview
This project explores hotel booking data using Exploratory Data Analysis (EDA) and basic data cleaning techniques.
The goal is to understand patterns behind booking cancellations and analyze key factors such as lead time, hotel type, and pricing behavior.

📂 Dataset Information
The dataset contains hotel booking records with features such as:

🏨 Hotel type (City / Resort)

⏳ Lead time before booking

👨‍👩‍👧 Guests (adults, children)

🌍 Country of origin

📊 Market segment

💰 Average Daily Rate (ADR)

❌ Cancellation status (is_canceled)

🧹 Data Cleaning Process
Removed duplicate records

Checked dataset consistency

Verified missing values (none found in final dataset)

Exported cleaned dataset as cleaned_dataset.csv

📊 Exploratory Data Analysis
📌 Cancellation Distribution
Visualized how many bookings were canceled vs not canceled.

🏨 Hotel Type vs Cancellation
Compared cancellation rates between City and Resort hotels.

⏳ Lead Time Analysis
Studied how booking advance time affects cancellations.

📦 Outlier Detection
Identified extreme values in pricing (ADR) using boxplots.

🔗 Correlation Analysis
Analyzed relationships between numerical features using heatmaps.

🔑 Key Insights
Longer lead times are associated with higher cancellation probability.

Hotel type influences cancellation behavior.

Pricing (ADR) contains outliers that may affect modeling.

No strong multicollinearity found among features.

Dataset is clean and structured for further analysis.
